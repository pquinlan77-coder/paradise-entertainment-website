Website privacy

This website is a static informational site. It does not include an account registration system, advertising network, analytics service, or contact submission form. The site does not intentionally collect health details from visitors.

Our hosting provider may process technical information, such as IP addresses and request logs, to operate and secure the website. For example, GitHub Pages logs visitor IP addresses for security purposes.

External links
